1 Introduction
Scaling language models traditionally means stacking more sequential transformer blocks, which increases
depth, memoryfootprint, andlatencyinlockstep. Mixture-of-Experts(MoE)transformers[Fedusetal.,2022,
Lepikhin et al., 2021, Shazeer et al., 2017, Zoph et al., 2022] address parameter scaling by routing tokens
to expert subnetworks, but the layer structure remains monolithic; every position runs a single full-width
transformer block.
In a companion paper [Ternovtsii and Bilak, 2026], we found that routing topology is quality-neutral across
structurally different MoE variants. If topology is not the primary driver of performance, what is? Prior
work points to per-expert expressiveness: 65,536 rank-1 experts cannot replicate 256 rank-256 experts despite
matched parameters (PPL 47.51 vs 12.55; see Appendix A).
We investigate whether layer structure itself can be decomposed, presenting four contributions:
1.Mixture of Layers (MoL).MoLreplaces full-width transformer blocks withKparallel thin blocks at
dthin=256, connected via learned down/up projections. With dense FFNs, MoL achieves PPL30.95±0.11
(3 seeds, 85M params) on WikiText-103,2.98better than the full-width MoE baseline, surpassing the
rank-1 expressiveness ceiling (Section 2).
2.Hybrid attention for sparse routing.Scaling to more blocks degrades attention quality as each
block sees fewer tokens. To address this, one shared softmax block (global coverage) is paired with
Gated DeltaNet [Yang et al., 2024] routed blocks (O(T)linear attention on sparse subsets). DeltaNet
outperforms softmax by 0.85 PPL after controlling for parameters in the thin-block regime (dthin=256),
an advantage that vanishes atdthin=dmodel (Section 3).
3.Sparsedispatchwithwall-clockspeedup.Sparsedispatch(gather/scatter)yieldsupto4.9×forward-
pass speedup at high sparsity. DeltaNet 1+3of15 (198M total, 77M active, 3 seeds) achieves PPL29.99±
0.08, activating only 27% of blocks per token (Section 2.3).
4.Regime-dependent scaling.MoL’s advantage is data-regime dependent: it loses to dense on WikiText-
103 (103M tokens, multi-epoch) but wins on Cosmopedia v2 (15B tokens, single epoch), with a0.85PPL
swing across datasets. A dense DeltaNet control matches dense softmax to within 0.01 PPL, indicating
MoL’s gain is not driven by the attention swap (Section 5.3). At 1.3B-scale on FineWeb-Edu 20B tokens
(single seed each),MoLHybrid (2.08B total / 0.61B active, PPL 18.04) sits between iso-active Dense
Softmax 0.7B (18.53) and iso-total Dense Softmax 1.3B (15.03): 0.49 PPL ahead at iso-active, 3.01 PPL
behind at iso-total, with a 1.91–2.29×training-time tax that does not extend to inference (Section 5.5).
Unlike sequential hybrid designs that alternate attention types across layers [Glorioso et al., 2024, Qwen
Team, 2025],MoLmaintains full attention coverage at every layer through the shared block while confining
linear attention to sparse routed subsets.

whichgathersonly routed tokens per block, runs on compact tensors, andscattersresults back. This
eliminates wasted compute on non-routed tokens.
Correctness.Sparse dispatch produces numerically identical outputs to dense restricted attention (max
logit diff5.7×10−6on GPU,2.4×10−7on CPU).

3 Hybrid Attention
3.1 The Attention Coverage Problem
Scaling to more blocks with sparse dispatch creates an attention coverage problem. At 3-of-15, each block
sees only 20% of the sequence (mean inter-token gap of 25.6), compared to 60% at 3-of-5 (gap of 1.8).
Softmax-only sparse 3-of-15 achieves PPL 34.73 on WikiText-103, worse than 3-of-5 (32.04) despite using
2.2×more parameters; more parameters cannot compensate for reduced sequence coverage.
3.2 Architecture: Shared + Routed
Each split stage contains:
•Shared block(block 0): always active on all tokens, full softmax attention, providing global context
at every layer.
•Routed blocks(blocks 1–N−1): top-kselected by the router, sparse dispatch with Gated DeltaNet
[Yang et al., 2024] linear attention on their token subsets.
We denote configurations asS+KofN:Sshared blocks plus top-Krouted fromN−Scandidates, withN
total blocks. For example,1+3of15has 1 shared softmax block and selects 3 from 14 routed DeltaNet blocks,
activating 4 total.
3.3 Why DeltaNet in Routed Blocks
Gated DeltaNet is used in routed blocks; since the shared block already supplies global softmax context,
the routed blocks do not require precise quadratic attention. Adthin scaling sweep also shows DeltaNet

OnWikiText-103(103Mtokens,∼8epochs), MoLconsistentlyunderperformsdense: MoLK=5top-3(85.3M,

6 Related Work
MoE and layer modularity.Standard MoE [Fedus et al., 2022, Shazeer et al., 2017, Zoph et al., 2022]
routes tokens to FFN experts within a full-width layer. In contrast,MoLroutes over whole transformer
blocks at reduceddmodel. Layer-level modularity work modifieswhichlayers execute (MoD [Raposo et al.,
2024], MoLEx [Teo and Nguyen, 2025], MoR [Bae et al., 2025], MoEUT [Csordás et al., 2024]); sub-network
parallelism partitions weights (UoE [Yang et al., 2025]), the FFN only (FlashMHF [Zhang et al., 2026]), or
sub-blocks (AltUp [Baykal et al., 2023]); MoM [Gong et al., 2024] and MoUE [Chen et al., 2026] pool/share
modules, all at fulld model. No prior work combines parallel blocks, reduced-dmodel down/up projections
(used as fine-tuning in adapters/LoRA [Houlsby et al., 2019, Hu et al., 2022]), top-kblock routing, and
hybrid attention.

B Active Compute Scaling
Scaling fromK=12toK=128active rank-1 experts (10×more active FLOPs,N=4096, 138M params,
τ=15) yields PPL 33.22, closing only 19% of the 3.67-PPL gap to the dense baseline (30.26) despite10×

of active experts.
C Activation-Level Gating
Squeeze-and-Excitation (SE) gating [Hu et al., 2018] applied to expert activations (notdmodel-dimensional
vectors) achieves PPL 31.82, the best iso-parameter rank-1 result. A small MLP (K→4→K, 896 extra
parameters total) modulates routing weights based on expert activation magnitudes. SE closes 46% of the
dense gap (33.93→31.82, target 29.36). Neither active compute scaling nor activation gating fully close the
gap, motivating the structural decomposition ofMoL.

F Block-Parallel Model Sharding (Analytic)
MoL’s thin blocks have no within-layer cross-block data dependencies, which makes them a natural fit
for expert-parallel placement. A prototype distributing 14 routed blocks across 3 GPUs over PCIe (with
differentiable all-to-all token dispatch) yields a 38% per-GPU parameter reduction and 23% VRAM savings
at a 34% wall-clock penalty; the penalty is expected to shrink substantially on NVLink. Compared to
Megatron-style tensor parallelism, which incurs two all-reduces per transformer layer in the forward pass
[Narayanan et al., 2021], and to standard expert-parallel MoE, where dispatch/combine collectives per MoE
layer can dominate step time at scale [DeepSeek-AI, 2024],MoL’s block-parallel design requires only one
all-reduce per split stage and keeps attention local to each block. A larger-scale strategy would combine
block placement (primary axis), pipeline depth, and context parallelism inside long routed sub-sequences;
we leave a measured throughput study to future work.
